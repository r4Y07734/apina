# Apina.app landing page

A self-contained, responsive landing page concept for Apina — dark, API-first, and focused on AI tooling.

## Run locally

Open `index.html` directly in a browser, or serve the folder with any static server.

Example:

```bash
python3 -m http.server 8080
```

Then visit `http://localhost:8080`.

## Notes

- Pure HTML/CSS/JS; no framework or build step required.
- Navbar is pure `#000000` as requested.
- Includes responsive navigation, code tabs, copy interactions, tool cards, API timeline graphic, and CTA.
- The API examples are UI copy/illustrative endpoint examples and should be connected to real Apina endpoints before production use.
